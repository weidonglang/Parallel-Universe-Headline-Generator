# 平行宇宙头条生成器

一个基于 **Spring Boot + 原生前端页面** 的轻量级趣味项目。  
用户输入一个人物、宠物、物件、事件，甚至一个抽象概念，系统会自动判断主题类型，并生成一条“一本正经但离谱”的平行宇宙快讯，包括：

- 头条标题
- 现场追踪
- 当事人发言
- 后续建议
- 话题标签

适合用来练手 Spring Boot、做趣味 Web Demo，或者作为“模板驱动内容生成”的小型原型项目。

---

## 项目预览

这个项目启动后会提供一个简单的网页界面。  
你可以输入例如：

- 老王
- 小橘猫
- 咖啡机
- 周一早会
- 自由

系统会返回一组风格统一的“离谱新闻”内容。

---

## 功能特性

### 1. 输入主题，自动生成平行宇宙头条
输入任意主题后，后端会生成一组结构化新闻内容，而不是只返回一句标题。

### 2. 自动识别主题类别
系统会根据输入内容自动判断它更像：

- 人物
- 动物
- 事件
- 物件
- 抽象概念

然后匹配不同的文案模板。

### 3. 同样输入，结果稳定
项目使用基于输入内容的随机种子。  
这意味着同一个输入通常会得到同一组输出，便于复现和调试。

### 4. 零数据库依赖
当前版本不依赖数据库，也不依赖外部 AI 接口，启动简单，适合本地快速运行。

### 5. 前后端一体化
前端页面由 Spring Boot 静态资源直接提供，页面通过 `/api/universe-news` 接口拉取生成结果。

## 接口说明

### `GET /api/universe-news`

根据输入主题生成一条平行宇宙新闻。

#### Query 参数

| 参数名     | 类型     | 是否必填 | 说明                     |
| ------- | ------ | ---: | ---------------------- |
| `topic` | String |    否 | 输入主题，例如“老王”“小橘猫”“周一早会” |

#### 响应字段

| 字段名        | 类型           | 说明        |
| ---------- | ------------ | --------- |
| `anchor`   | String       | 归一化后的输入主题 |
| `headline` | String       | 生成的头条标题   |
| `scoop`    | String       | 现场追踪文案    |
| `quote`    | String       | 当事人发言     |
| `action`   | String       | 后续建议      |
| `tags`     | List<String> | 随机组合的话题标签 |

## 核心实现思路

### 1. 输入归一化

如果用户没有输入内容，系统会使用默认主题，例如“今天的你”。

### 2. 主题识别

后端会通过关键词和文本特征，判断输入更接近哪一类主题，例如：

* `猫 / 狗 / 宠物` → 动物
* `会议 / 早会 / 团建 / 午休` → 事件
* `咖啡机 / 键盘 / 手机` → 物件
* `自由 / 灵感 / 运气 / 幸福` → 抽象概念
* 短名字或带人物称呼的输入 → 人物

### 3. 模板选择

不同类别对应不同的模板集合，包括：

* 头条模板
* 现场描述模板
* 发言模板
* 行动建议模板
* 身份称号
* 标签词库

### 4. 稳定生成

项目会使用输入内容的哈希值作为随机种子，因此同一输入可得到稳定输出，避免每次刷新都完全不同。
